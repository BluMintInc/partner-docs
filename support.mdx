## Reference and support {#reference-and-support}

| Where | What it covers |
| --- | --- |
| [API reference](/api-reference/introduction) | Every endpoint and callback, with full request and answer schemas. The API reference leaves out the /api prefix, which its server address already carries. |
| [Game partner setup form](https://app.blumint.com/contact/game-partner) | Request your API keys by telling BluMint about your game. |
| [Contact form](https://app.blumint.com/contact) | Ask for your production key, turn automatic lobbies off, change an answer you gave in the setup form, or ask a question. For a question about one match, include its `Idempotency-Key` or your `matchId`. |
